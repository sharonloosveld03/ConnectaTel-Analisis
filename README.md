# Análisis de Clientes de ConnectaTel

## Descripción del proyecto
Proyecto de análisis exploratorio de datos de una empresa de telecomunicaciones con operaciones en México y Colombia.

El objetivo es identificar patrones de uso de servicios móviles, detectar valores atípicos y segmentar clientes para generar recomendaciones comerciales.

## Herramientas utilizadas
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Metodología
1. Exploración y limpieza de datos.
2. Análisis estadístico descriptivo.
3. Identificación de valores atípicos mediante boxplots y el método IQR.
4. Segmentación de clientes por edad y nivel de uso.
5. Visualización de resultados y elaboración de recomendaciones.

## Principales hallazgos

**Segmentación por edad:**
- Adultos: 2.018 clientes.
- Adultos mayores: 1.222 clientes.
- Jóvenes: 760 clientes.

**Segmentación por uso:**
- Uso medio: 2.943 clientes.
- Bajo uso: 779 clientes.
- Alto uso: 278 clientes.

Se identificaron valores atípicos superiores en el consumo de mensajes, cantidad de llamadas y minutos de llamadas.

## Recomendaciones
- Evaluar planes adaptados a diferentes niveles de consumo.
- Diseñar estrategias de retención para los segmentos de clientes.
- Analizar los patrones de consumo elevado para identificar oportunidades comerciales.
- Mantener controles de calidad de datos para futuros análisis.
